# Videos · Módulo 4 Dispensación (self-hosted)

Coloca aquí los mp4 de las lecciones. El SPA los sirve desde
`/videos/dispensacion/<archivo>.mp4`. El nombre debe coincidir con el campo
`video` de cada lección en `src/data/dispensacion.ts`. Mientras falte el archivo,
la lección muestra "Video en preparación".

> La lección **"Introducción y consideraciones"** es de solo lectura, **sin video**.
